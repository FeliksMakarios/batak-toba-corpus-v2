# Panduan Kontribusi

Terima kasih atas minat berkontribusi pada pedoman dan korpus UD Batak Toba.

## Jenis kontribusi yang diharapkan
- Validasi linguistik contoh anotasi oleh penutur asli Batak Toba.
- Usulan keputusan untuk isu terbuka (lihat akhir `guidelines/02_pedoman_anotasi_v1.md`).
- Perbaikan ejaan, glosa, atau terjemahan Indonesia.
- Penambahan kalimat teranotasi mengikuti pedoman.

## Alur
1. Buka issue untuk mendiskusikan usulan sebelum perubahan besar.
2. Fork dan buat branch deskriptif (mis. `voice-di-mapping`).
3. Untuk perubahan CoNLL-U, pastikan lolos validasi format (10 kolom, satu root, HEAD valid).
4. Ajukan pull request dengan penjelasan keputusan linguistik dan rujukannya.

## Konvensi anotasi
- Ikuti UD v2 dan pedoman di folder `guidelines/`.
- Kolom XPOS dikosongkan (`_`).
- Sertakan rujukan (Nababan, Cumming, Erlewine, UD ID, UD Tagalog) untuk keputusan baru.
- Tandai keputusan yang belum final dengan komentar `# TODO:` di file.

## Kontak
Ajukan lewat issue di repositori ini.
